Answers you can use

Diagrams, tables, charts, kanban boards, PDFs, Markdown, spreadsheets, video and live web pages show up on the canvas. Resize them, place them side by side, or open one full screen and zoom in. They stay live as the work goes on.

Keyboard first

Ctrl↑ walks the objects, Enter opens one, Esc is always the way back. CtrlK does the rest.

Canvas or CLI

One switch between the canvas and the agent's own screen. It stays where it is, and Ember remembers your pick.

Notes and todos, outside sessions

A sticky note with CtrlShiftN, a todo list in the sidebar. Every agent can read them, add to them and tick things off.

Computer use you can watch

The agent reads your screen as text and acts with a pointer you can see, one smooth move at a time. STOP is always on screen.

One memory for all your agents

What one agent learns about you and your projects, the others know too. Shared skills, shared instructions.

Questions.

What does it cost?

Nothing. Ember is free and open source, with no account and no paid tier. It runs your agent CLI with that CLI's own sign-in, so whatever you already pay for it stays the same.

Which agents does it work with?

Claude Code, Codex, Gemini CLI, Cursor Agent, OpenCode, Copilot CLI, Qwen Code, Amp, Aider and Crush. Claude Code and Codex get the full canvas; the others run in the same sessions and keep improving.

Can an agent click around my computer?

Only when you ask it to, with a pointer you can see and a STOP button that is always on screen. You can switch computer use off from CtrlK.

Does it run on Mac or Linux?

Not yet. Ember is for Windows 10 and 11 (x64) for now.

Windows warned me about the installer. Is it signed?

Not yet. SmartScreen may warn the first time: click More info, then Run anyway. Every build comes from the public source on GitHub.

What leaves my machine?

Your work goes where your agent CLI already sends it. Ember has no account and no telemetry. Notes, todos and the shared memory are plain files in your user folder.
