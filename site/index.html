Questions.

Do I need an API key?

No. Ember never asks for an LLM API key. It runs the coding CLI you already have installed (Claude Code, Codex, Gemini CLI, Cursor Agent, OpenCode or Copilot CLI) using that CLI's own login and your own subscription. Ember doesn't bill you for anything. It has no field for a key anywhere and stores no credentials.

What does it cost?

Nothing. Ember is free, with no account, no trial and no paid tier. Whatever your CLI costs is between you and its provider, the same as it is today.

Does it run on Mac or Linux?

Not yet. Ember is Windows only for now (Windows 10 and 11, x64). It's built around ConPTY and the Windows glass effects, so Windows came first.

Windows warned me about the installer. Is it signed?

Not yet. Ember's releases aren't code signed, so SmartScreen may warn the first time: click More info, then Run anyway. Every build comes straight from the public source on GitHub Actions, and each release lists SHA256 checksums so you can check the file; see the code signing policy. It installs just for you and never asks for admin rights.

What leaves my machine?

Your work goes where your CLI already sends it, the same as in any terminal. Ember has no account and no telemetry. The few calls it makes on its own belong to features you can see and turn off, like the plan usage in the sidebar and the Map checking your repos for changes. Your settings, notes, todos and maps are plain files in your user folder.

Will it change my PowerShell setup?

No. Ember replaces the window, not the shell. Your profile, modules, oh-my-posh and PSReadLine run as they always have. Shell integration wraps your prompt without replacing it, and you can turn it off.

Bring your CLI. Ember does the rest.
