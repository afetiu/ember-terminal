01 — Bring your own CLI

It never asks for an API key.

Ember drives the coding CLI you already have installed, signed in the way you already are, on your own subscription. You choose which one it uses. There's no key field to fill in and no Ember account.

On first launch Ember checks which CLIs are on your machine and offers a one-click install for the rest.

02 — The tour

Built around the way agents actually work: several at once, mostly while you're looking elsewhere.

Sessions are cards that tell you what they're doing.

Sessions sit in a sidebar, not a tab strip, because each one carries real state. Ember reads the state off the screen itself: working, waiting on you, or idle. A small animated sprite on each card shows it, so you can see which agent needs you without opening anything.

Cards also carry the git branch and dirty count, and the one waiting on you tints amber with a quiet chime. Nothing goes to the notification centre.

A panel beside every terminal, for the agent to draw on.

Each terminal has a second half. Over MCP, the agent puts the shape of its answer there: a diagram, a table, a mockup, a chart. The panel stays closed until there's something on it, then springs open.

It works both ways. Buttons in the panel type into the terminal beside it. Point at a row and ask about it, and your question goes to the session with that row quoted.

The Map: your project's architecture, kept current.

CtrlShiftG opens a zoomable picture of a project: areas, repos, apps, services, data stores and the connections between them. The agent surveys it once, then keeps it up to date. When something actually changes, it updates the parts that moved instead of redrawing, so the picture stays where you learned it.

Sessions at work show up as live rings on the parts they're editing. New and changed parts glow, and every version is kept so you can scrub back.

Overview: every session on one screen.

CtrlShiftS lays out every session as a card: its state and for how long, its folder and branch, how much context it has used, and the last thing its agent said. Cards that need you sort first. Type into any of them from right there.

And the rest of a terminal you'd want to live in

  • Notes and a todo list

    Plain Markdown files in a folder you own. The agent reads and writes them with the notes and todo commands, no tool setup needed.

  • CtrlK and the ember CLI

    Every action the window has is one command. Run it from the command line, a button, or ember split right in any shell, agents included.

  • Splits

    Put a terminal beside or below the one you're in, then drag the seam.

  • 49 themes

    Ember's own palettes plus ports of Tokyo Night, Catppuccin, Dracula, Nord, Gruvbox and more. Each one re-tints the whole window, not only the text.

  • A caret that travels

    Two springs, a stiff head and a slack tail. It stretches with speed and settles to nothing. You can tune it or turn it off.

  • Acrylic glass

    Frosted while you're in the window, plain see-through glass when you're not. Mica or flat are one setting away.

  • Zen mode

    CtrlShiftEnter hides all the chrome. Just the terminal.

  • Your shell, untouched

    PowerShell runs through the same ConPTY Windows Terminal ships with. Your profile, oh-my-posh and PSReadLine behave exactly as before.

03 — How it works

Three steps, none of them a sign-up form.

  1. 1

    Install

    Run the installer. It installs just for you, so there's no admin prompt, and adds Start Menu and desktop shortcuts.

  2. 2

    Pick your CLI

    Ember finds the coding CLIs you already have. Choose one, or install another with one click.

  3. 3

    Work

    Open sessions, hand them tasks, and keep an eye on all of them from the sidebar. The panel and the Map fill in as you go.

05 — Questions

Asked before you download.

Do I need an API key?

No. Ember never asks for an LLM API key. It runs the coding CLI you already have installed (Claude Code, Codex, Gemini CLI, Cursor Agent, OpenCode or Copilot CLI) using that CLI's own login and your own subscription. Ember doesn't bill you for anything. The only keys it ever takes are for the optional voice features, and only if you choose to turn them on.

What does it cost?

Nothing. Ember is free, with no account, no trial and no paid tier. Whatever your CLI costs is between you and its provider, the same as it is today.

Does it run on Mac or Linux?

Not yet. Ember is Windows only for now (Windows 10 and 11, x64). It's built around ConPTY and the Windows glass effects, so Windows came first.

Windows warned me about the installer. Is it signed?

Not yet. The installer isn't code signed, so SmartScreen warns you the first time you run it. Click More info, then Run anyway. It installs just for you and never asks for admin rights.

What leaves my machine?

Your work goes where your CLI already sends it, the same as in any terminal. Ember has no account and no telemetry. The few calls it makes on its own belong to features you can see and turn off, like the plan-usage chip and the Map checking your repos for changes. Your settings, notes, todos and maps are plain files in your user folder.

Will it change my PowerShell setup?

No. Ember replaces the window, not the shell. Your profile, modules, oh-my-posh and PSReadLine run as they always have. Shell integration wraps your prompt without replacing it, and you can turn it off.
